# Code of Conduct

Participation in this project is expected to stay professional, direct, and respectful.

## Expected behavior

- Assume good intent, but be precise about technical disagreements.
- Focus criticism on code, behavior, and tradeoffs, not on people.
- Keep review feedback actionable and specific.
- Respect the time of maintainers and contributors by doing basic reproduction and verification work before escalating.

## Unacceptable behavior

- Harassment, threats, or discriminatory language.
- Personal attacks, dogpiling, or deliberately hostile review behavior.
- Publishing private or security-sensitive information without consent.
- Repeated bad-faith disruption of issues, pull requests, or release threads.

## Enforcement

Project maintainers may edit, hide, lock, or close discussions and pull requests that violate these expectations. Repeated or severe violations may result in removal from the project spaces.

If a thread is becoming unproductive, stop the escalation and move back to concrete reproduction steps, code, or documented policy.
